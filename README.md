## ⭐ Proyectos Destacados

### 📚 **Miniprojecte 1 — Clon de la Viquipèdia (Mi primer proyecto HTML, al que le tengo mucho cariño)**  

**Repositorio:** <a href="https://github.com/HamzafpllefiaSMX/miniproyectowikipedia" target="_blank" rel="noopener noreferrer">github.com/HamzafpllefiaSMX/miniproyectowikipedia</a>  
**Demo (GitHub Pages):** <a href="https://hamzafpllefiasmx.github.io/miniproyectowikipedia/" target="_blank" rel="noopener noreferrer">hamzafpllefiasmx.github.io/miniproyectowikipedia/</a>

**Descripción:**  
Este fue mi **primer proyecto serio en HTML** y le guardo mucho cariño porque fue con el que aprendí a pensar como estructurar una página desde cero.  
El objetivo era **recrear un artículo de la Viquipèdia** respetando su jerarquía: secciones, subsecciones, imágenes, tablas, listas y enlaces. No se trataba de copiar y pegar, había que usar HTML semántico.

**Tareas completadas:**
- Crear la estructura completa (`index.html`) con la jerarquía correcta de headings (`<h1>`, `<h2>`, `<h3>`).  
- Implementar un menú de navegación con `<ul>` y enlaces internos (`id`) para cada sección.  
- Añadir imágenes con `alt` y añadir enlaces con `target="_blank"` para abrir en una nueva ventana
- Subir el proyecto a GitHub y desplegarlo con **GitHub Pages**.

**Tecnologías:** HTML, CSS básico, imágenes, i enlaces internos/externos.

**Lo que aprendí:**  
- Importancia de la semántica HTML y jerarquía de contenido.  
- Cómo construir menús y un poco de flexbox para el menu  
- Buenas prácticas con imágenes y licencias (atribuir contenido a la Viquipèdia / CC BY-SA).  
- Flujo completo: archivos locales → repo en GitHub → GitHub Pages.
